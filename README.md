# 🤖 AI Chat Application

An AI-powered chat application built using React and Django, integrated with Google Gemini API.

---

## 🚀 Features

- AI-powered conversations
- Chat history management
- Recent and previous chats
- Clean and responsive UI
- Real-time message interaction

---

## ⚙️ Tech Stack

- React.js
- Django
- Python
- Gemini API

---

## 📌 Project Goal

To build an AI chat system with persistent conversation history and real-time AI responses.
